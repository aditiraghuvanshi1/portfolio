Aditi Raghuvanshi · 3D Portfolio

An interactive, animated portfolio website that showcases my real-life, problem-solving projects. 
The whole site lives in a single HTML file, so there is nothing to install or build.


Features
3D animated background built with Three.js (floating wireframe shapes and particles that react to mouse movement and scroll)
Custom animated cursor with a trailing sparkle effect. The ring changes shape on links, project cards, and icons
Projects that slide in from alternating sides as you scroll, with 3D tilt on hover and a click animation
Built-in ambient music with a toggle button and live equalizer bars (generated in the browser using the Web Audio API, so no audio files are needed)
Basic info panel with name, college, contact, and city
Floating social icons in the contact section
Scroll progress bar, animated heading, moving project banner, and counting number.
Responsive layout for phones, tablets and desktops
Respects the prefers-reduced-motion setting and falls back gracefully if WebGL is unavailable
